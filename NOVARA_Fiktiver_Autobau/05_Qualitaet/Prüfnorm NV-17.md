# Prüfnorm NV-17

> [!note] Erfundenes Regelwerk
> NV-17 ist eine interne Norm der NOVARA-Fiktion, kein reales Prüf- oder Zulassungszeichen.

## Freigabekriterien für N7
Alle Kriterien müssen gleichzeitig erfüllt sein.

| Prüfung | Kriterium |
| --- | --- |
| Identität | Fahrzeug, Formrevision und Kernbindung stimmen überein |
| Geometrie | Außenkontur entspricht FB-N7-C, kein Spiegelheck |
| Bindung | mindestens 92 BG; niedrigster Messwert zählt |
| Fugen | höchstens 3 PF; höchster Messwert zählt |
| Leitnetz | keine milchigen Leitpfade |
| Lenkung | drei Links-Rechts-Zyklen ohne Restmuster |
| Anker einzeln | jeder mindestens 12 AE |
| Anker gemeinsam | mindestens 24 AE |
| Ankerwiederholung | drei Vollaktivierungen ohne Restmuster |
| Fahrtprüfung | 20 SM und drei zusätzliche Vollankerungen |
| Ladungsbilanz | Verbrauch nach Modell, Rest mindestens 80 LM |

## Prüfablauf und Bilanzgrenze
Nach den stationären Funktionsprüfungen werden beide Speicher auf zusammen **800 LM** gesetzt. Erst dann beginnt die dokumentierte Fahrtbilanz. Die drei stationären Vollaktivierungen zählen somit nicht zum Verbrauch der anschließenden Fahrtprüfung.

Für die Fahrt gelten 20 × 2 + 3 × 5 = **55 LM**, verbleibend **745 LM**. Eine Abweichung sperrt das Fahrzeug zur Diagnose; eine Toleranz ist im Kanon nicht vorgesehen.

## Entscheidung
Fehlt eine Prüfung, lautet das Ergebnis **unvollständig**, nicht freigegeben. Ein tatsächlicher Fehler bedeutet **gesperrt**. Nacharbeit erfordert eine Wiederholung der betroffenen Prüfung und aller dadurch beeinflussten Prüfungen. Siehe [[Abnahmeprotokoll N7-014]].
